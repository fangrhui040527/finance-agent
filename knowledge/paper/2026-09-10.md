## Mistakes

**The all-cash gap is a choice, not a constraint — measured tonight.** Three consecutive observe nights have written nothing gradeable, and I have been recording that as a property of the phase. It is not. A dry run against tonight's book:

```
$ ask.py paper decide --dry-run --weights "MYX:5183=0.12" ...
DRY RUN - would record 1 target(s) for 2026-09-10 (week 1, observe: ...)
  MYX:5183      12.00%  decision
  1 prediction(s) logged:
    paper-2026-09-10-myx5183-21d-e215  +21d  grades on 2026-10-10
  observe phase: this is logged and will be graded; it is not applied
```

A non-cash target during observe **is** recorded and **does** log a gradeable prediction. The observe phase logs and grades; it only declines to apply. So the reason three nights have produced nothing gradeable is entirely that all-cash writes no row — and the stores confirm it again tonight:

```
data/paper.db     targets 0, applications 0, position_changes 0
data/learning.db  predictions 0
git               neither database modified
```

At 12% the same command would have written a target and a prediction due 2026-10-10. At 11% it was refused for a real reason — `[lot] MYX:5183: 11.00% is below one lot (USD 118.54 = 11.9% of equity)` — which is the sizing floor doing its job.

I am not manufacturing a position to make the instrumentation produce rows; a position taken to be gradeable is worse than no rows. But the previous two pages framed this as the phase's doing, and that framing was wrong.

**Carried, and now three nights old:** `paper decide` prints "this is logged and will be graded" on an input where nothing is logged and nothing can be graded. The line is false for exactly one input, and that input is the one the book has produced every night of its life.

## Lessons proposed

- A phase that logs but does not apply still needs something to log. "Nothing"
  is a valid decision and an invalid record, and a book that only ever decides
  nothing cannot be told apart from a book that is broken.
- Price without evidence is not a thesis, however large the price move. The
  book's best performer over four sessions is also the one name with an empty
  store, and those two facts are related through the collector, not the company.
- When an instrument's behaviour is attributed to a rule, check the rule. Two
  pages blamed the observe phase for an empty ledger; one dry run showed the
  phase was willing.
