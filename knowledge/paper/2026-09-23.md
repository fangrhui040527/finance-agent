## Lessons proposed

- A migration that rewrites a ledger's history rewrites the pages that quoted it. A count copied onto a page (19 marks) is true only of the ledger version it was read from, so the page needs the commit it was read at.
- A decision's clock is auditable only when every store stamps the same instant. Tonight's row has one timestamp in both stores and yesterday's has two, four hours apart. Restamping the one old row would make the record look consistent but would not change when the decision was actually taken.
- A control book first invested on a cost-bearing day starts behind. The −0.83% on its first mark includes entry fees, FX spread and slippage that the decided book, all in cash, has not paid, and a grade that ignores this favours cash.
