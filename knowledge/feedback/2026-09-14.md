## Lessons proposed

- A residual is only "idiosyncratic" if every systematic factor has a column. With the sector beta fixed at 0, a sector-wide selloff is indistinguishable from company news, and the label asserts the difference the model cannot make.
- The same defect can arrive twice in one system by different routes: alpha was computed and not printed, the sector factor is not computed at all. The first was fixable by reporting; the second needs data.
- A confirming observation written as a test is worth more than one written as a hope. The 09-13 page named the exact story it would take to raise confidence in Petronas Chemicals, and the next sweep produced it — which is why the confidence moved by a stated amount rather than by feel.
- An alert that closes because the rule was wrong is a different event from one that closes because the data arrived, and a log that does not distinguish them teaches the wrong lesson about how healthy the system is.
- A source can degrade from late to absent between two pages. `nst_business` was a cadence warning on Sunday and a 404 on Monday; only the page that reads both notices the direction.
