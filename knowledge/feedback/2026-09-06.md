## Lessons proposed

- A name matched inside a PLACE name is a false positive the escalation gate cannot catch, because the gate only asks whether a watched instrument was named. "Maybank Highway at Main Road closed after a crash" reached the queue as a Maybank story. Falsifiable: if the linker required the match to sit next to a company-shaped token (Berhad, Bhd, Group, the ticker, a financial noun) or refused a match immediately followed by a road/place noun, this article would not link, and the three-story Maybank set for this page would be two.
- A fetch timestamp is not a data date. The price cache recorded `fetched_on 2026-09-06` for every Bursa symbol while its newest bar stayed at 2026-09-04, so a freshness check written against the fetch time would have called this cache current. Falsifiable: a staleness rule that reads the newest OBSERVATION date, not the fetch date, flags this cache today; one that reads the fetch date does not.
