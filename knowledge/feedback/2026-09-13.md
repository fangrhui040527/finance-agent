## Data quality

### Answered: the missing term is the regression intercept

The 2026-09-12 page asked which term is absent from the pack's printed decomposition, given that the components never sum to the printed return. **It is alpha, the fitted intercept**, and the omission is structural rather than a rounding artefact. `engines/attribution/decompose.py:197`:

```python
expected = fit.coefficients[0] + c_mkt + c_sec + c_sty
ar = realised_local - expected
```

`coefficients[0]` enters `expected`, so it is subtracted out of the idiosyncratic residual — but it is not one of the five entries in `contribs`, so it is never printed. The printed components therefore under-account for the return by exactly the fitted daily drift.

Measured on a synthetic series with a known drift of +0.200%/session: fitted alpha **+0.00213**, and return minus the sum of all five printed components **+0.00213**. Identical to five decimal places.

Per name tonight, which is to say each name's fitted daily alpha over its 120-session window:

```
Maybank        -0.08pp    Petronas Chemicals  +0.16pp    Press Metal  +0.05pp
Tenaga         -0.01pp    IHH                 -0.09pp    Genting      -0.24pp
```

Two things this settles. **It is not the proxy's fault** — the same gaps, to within 0.03pp, were present against the ETF when the market leg was +0.00%, so a complete change of market instrument left them untouched. And **the values are economically legible**: PCHEM's +0.16pp/day is the drift of a name that ran 19% in a week; Genting's −0.24pp/day is a name in a downtrend. The term is real and the decomposition should show it rather than bury it in a residual labelled "idiosyncratic". Genting's 0.24pp is twice its entire printed idiosyncratic component.

## Lessons proposed

- A proxy is validated by the betas it produces, not by whether it returns data.
  The ETF returned a close on 1,067 of 1,231 sessions and gave a bank a beta of
  0.12; the failure was visible in every fit for three years and nothing was
  looking at the fits.
- When a fix lands, measure the same names both ways before writing about it.
  "The proxy is better" is a claim; a beta table with the old column beside the
  new one is a finding, and it cost one script.
- An unexplained share that survives a change of instrument is a measurement;
  one that does not was arithmetic. Petronas Chemicals held 98% and IHH fell
  from 100% to 72% — only one of those was ever about the company.
- A residual labelled "idiosyncratic" will absorb any term the printer forgets,
  silently and with a plausible name. The gap was visible for two pages before
  anyone read the line that produced it.
- Waiting is an action and it needs its own evidence. `sweep --due` named a slot
  as owed and the correct response was to do nothing, because the delay
  distribution — not the cron — says when a run is missing.
