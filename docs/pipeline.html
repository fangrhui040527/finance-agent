The Analyst Mind Pipeline

Six stages from a raw wire story to a position size. Every one of them is a gate — so each diagram draws what falls out alongside what passes through. The dropping is the design; a pipeline that kept everything would produce a confident answer for every input.

▪

The whole flow

Data enters once, on the left. It is reduced at every boundary, and the guardrail rails fire on the right at each one.

1

Ingest — bronze to silver

Dedup runs before indexing, so a wire story syndicated to forty outlets is one document, not forty pieces of corroborating evidence.

Duplicates

Near-duplicate hash on the body. Syndication collapses to one document.

Unlinked items

No resolvable instrument, so no claim can rest on it.

Stale items

Freshness is a hard filter at retrieval, not a ranking penalty.

2

Retrieval — and the two rewrites

Web search is never the default. It fires only after two failed rewrites, and only if the calling agent opted in.

3

Attribution — the gate before the story

The decomposition decides whether a cause is even sought. This ordering is the single most important edge in the system.

Why the first exit exists

The attribution_unavailable branch was added after stress testing: a NaN return used to reach a verdict and render as "nan% unexplained" — a confident finding built on a value that was not a number. The gate now refuses at the boundary and names the offending field.

4

Sizing — four caps, one floor

Four ceilings and one floor. The smallest ceiling wins; the floor is a separate gate. A decision that breaches any of them cannot be constructed at all.

5

The learning loop — the only cycle

Everything above is a one-way flow. This is the single feedback edge, and it is deliberately slow: the gate's default answer is "no lesson".

The whole flow runs on mock data with no network and no API key — make verify walks all fourteen sections in about a tenth of a second. If it ever needs a network connection, something has leaked across the adapter seam and that is a defect, not a configuration problem.

Not financial advice. This pipeline produces candidacy bands, calibrated probabilities, attributions and sizing constraints with evidence chains. It makes no recommendations and cannot place orders.
